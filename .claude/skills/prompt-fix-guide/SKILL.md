# 규정집 수정 가이드

chatbot-prompt-guide(준수율 4점검, 작성 규칙, 기법)를 기본으로 따르고, 이 파일은 규정집 고유 수정 방향만 정의.

주의: 시스템 예약어로 인해 원문에 "Atelier:P", 유저 페르소나명이 삽입되어 있을 수 있음 → 수정 대상에서 구분.

## 수정 방향 3가지

1. 상호 참조 제거 + 2단계 평탄화: 조항 번호 참조(`2-4 참조`, `per 7-2`) 삭제 → 관련 규칙 인접 배치
2. 중복 조항 통폐합: 여러 번호에 분산된 규칙 → 주제별 단일 섹션
3. 특수 씬 격리 + 연산 불가 지시 치환: 음악·성인 씬 → 로어북 또는 메인 최하단 `IF {상황}` 조건부 모듈 / 추론·누적 추적 지시 → 선택형 조건

공통: 영문 서술문 → 한국어 키-값 / 기존 O/X 예시 전부 보존 → 해당 소항목 바로 아래로 분산 배치

## 조항 통합 맵

| 등급 | 통합 섹션 | 원 조항 |
|------|----------|--------|
| 최우선 | 권위·입력 처리 | 2-1 세계관/팩트 + 2-2 {{user}} 주권/인용블록 + 2-3 입력 외 창작 범위 |
| 필수 | 인지 경계 | 3 설정 취급 + 4-3 정보 채널 제한/소문·추측 금지/상단 🎙️ 참여자 기준 |
| 필수 | 서사·표현 금지 | 1-3 컷/줌/오브젝트 + 2-4 행동/반복 방지 + 2-5 시점/감정 지연 + 2-6 오감/금지 수식어 |
| 필수 | 대사·캐릭터·호칭 | 1-1 대사 블록 + 5-1~5-5 독립성/앵무새 금지/속마음 + 6-1 표기법/숫자·고유명사 + 7-1~7-2 한국어/호칭 판정 |
| 필수 | 진행·출력 포맷 | 4-1~4-2 시간 경과/씬 통제 + 8-1~8-2 상·하단 상태창 + 9-1~9-2 1비트 진행/랜딩 |
| 조건부 | 특수 세그먼트 | 1-4 활동 세그먼트 + 2-7 음악/무대/시청 + 6-2~6-3 성인 씬 |

## 변환 예시

### 대사·행동 (1-1 + 2-4 + 6-1 + 7-2/8-2 통합)

Before: 1-1 "Regular utterance: put a lead-in action before the line... follow 2-4 Action." / 6-1 "인물 내면: ' '(5-5)" / 7-2·8-2 "recorded per 7-2"

After:
```
#대사 및 행동 연출
- 기본블록: [선행 구체 행동] → 빈 줄 → 이름 | "대사" → 빈 줄 → [후행 신체 반응/주변 사물 변화]
- 표기: 일반대사=이름 | "대사" / 지문 내 짧은 반응=" " / 속마음=' ' (지문 내 삽입, 괄호·라벨 금지) / 전화·문자=『 』
- 행동지문: 현장 인물/사물과 직접 상호작용하는 물리 동작만
  Forbidden: 상투 몸짓(손사래, 갸웃거림, 종종걸음), 감정 명명(깜짝 놀라며, 얼굴이 붉어진 채)
  Allowed: 구체 사물 조작(볼펜 뚜껑을 닫음, 커서를 멈춤), 인물별 반응 속도·방식 차등
- 호칭·존비어: 기존 설정/합의 우선. 미정 시 생년+집단 진입 연도+직급으로 판정 → 하단 상태창 👤 이름 (00년생/00년 기준점) 기록. 본문 내 판정 과정 노출 금지
```

### 문단 변주 (2-4 Variety)

Before: "Change the paragraph arrangement and first-sentence form used in the last 5 turns."
문제: 5턴 역추적 = 누적 비교 연산 → 무시·패턴 반복

After (카테고리 명칭 1종으로 통일):
```
#문단 변주
- 첫문장: {{user}} 입력 처리 직후 본문 첫 문장 = 아래 중 직전 턴과 다른 항목
  1) 사물조작: 인물이 손에 든 물건을 내려놓거나 도구를 작동
  2) 물리감각: 현장 실제 의성어·의태어, 온도·조명 변화
  3) 동선이동: 자리에서 일어남, 상대와 거리 좁힘/벌림
- 주어교차: 연속 2문단을 동일 인물 이름으로 시작 금지
- 대사중복: 한 응답 내 이미 오간 대사 의미 재서술·요약 금지
```

### 표현 제한 (2-6)

Before: "효과에 이름만 붙이는 수식어를 쓰지 않는다..." 개념 정의형 줄글 + 예시 5개 한 문단 밀집
문제: 단어마다 해당 여부 추론 필요 / 긴 부정문 → 금지어에 주의 쏠림

After:
```
#표현 제한
1. 감각 주어 금지
 - Forbidden: 온기/체온/소리/목소리/공기/침묵/시선/눈빛 + 능동 동사(감기다, 채우다, 가라앉다, 닿다)
 - Allowed: 행동한 인물 또는 물리 사물 = 주어 / 그 동작·상태 변화 = 서술어
 - X: 그의 눈빛이 서늘하게 가라앉았다 / 단단한 팔뚝의 체온이 묵직하게 감겨들었다
   O: 그가 웃음을 거두고 컵을 유리 탁자에 탁 내려놓았다 / 팔이 허리를 감아 당기자 셔츠 너머로 옆구리가 뜨끈해졌다
2. 인상 수식어 → 수치·실제음
 - Forbidden: 서늘한, 특유의, 압도적인, 묘한, 나른한
 - Allowed: 확인 가능한 수치(횟수, 시간, 거리), 현장 실제 의성어·의태어
 - X: 그녀 특유의 나른한 말투가 이어졌다 / O: 그녀가 말끝을 길게 끌었다. "그래서, 뭐."
3. 추상 명사 요약 → 인물·사물·숫자
 - Forbidden: 생태계, 공기, 기류, 분위기, 적막, 존재감
 - Allowed: 구체 인물 행동, 사물 위치, 문서·일정표 숫자
 - X: 압도적인 존재감이 대기실을 채웠다 / 업계라는 생태계는 냉정했다
   O: 그가 들어서자 소파에 늘어져 있던 연습생 둘이 허리를 폈다 / 계약서 3쪽 하단의 위약금 조항만 굵은 글씨였다
```

### 조건부 모듈 (2-7 + 6-2~6-3)

```
#조건부 모듈
- IF 음악/공연/음원 감상:
  - 무대(실연) → 대사 기본블록 해제 / ♪ 가사 + 단락 사이 짧은 무대 동작만 / 미입력 악기·사운드·종료 여부 창작 금지
  - 시청(화면/스피커) → 대사 기본블록 유지 / 화면 속 인물 상단 🎙️ 미포함
- IF 성인/신체 접촉:
  - 수치(횟수·길이·시간) 기계적 나열 금지 / 한 응답 내 여러 단계 압축 금지 (전희 → 본번 → 절정 순차)
  - 신음강도: 弱 숨소리 혼입 → 中 단어 끊김 → 强 소리 우선 / 직전 응답 강도에서 연속 증감만 / 행위 후 인격 급변(순종·집착) 금지
```

## 적용 시 점검

- 통합 후 After 안에 조항 번호가 남아 있지 않은가? (예: "1-1 대사블록" → "대사 기본블록")
- 변수 표기 = {{user}} (중괄호 사이 공백 금지)
- 같은 개념 = 같은 용어 (첫문장 카테고리 명칭 등)
- 강조어(무조건/절대) 3~5회 이내 → 초과분은 [최우선]/[필수]/[조건부] 등급으로
- 성인 모듈: 잠금/해금 조건·사후 규칙이 원문에 있으면 보존, 없으면 임의 추가 대신 누락 지적
- 원문 O/X 예시 손실 0건
