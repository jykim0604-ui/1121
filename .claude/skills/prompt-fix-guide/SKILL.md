# 규정집 수정 가이드

chatbot-prompt-guide(준수율 4점검, 작성 규칙, 기법)를 기본으로 따르고, 이 파일은 규정집 고유 수정 방향만 정의.

주의: 시스템 예약어로 인해 원문에 소하의 "Atelier:P", 유저 페르소나명이 삽입되어 있을 수 있음 → 수정 대상에서 구분.

## 수정 방향 3가지

1. 상호 참조 제거 + 2단계 평탄화: 조항 번호 참조(`2-4 참조`, `per 7-2`)와 깊은 계층 삭제 → 관련 규칙 인접 배치
2. 중복 조항 통폐합: 여러 번호에 쪼개진 규칙 → 주제별 단일 섹션
3. 특수 씬 격리 + 모호 표현 구체화: 음악·성인 씬 → 로어북 또는 메인 최하단 `[조건부 모듈]` + `IF {상황}` 꼬리표 / 연산 불가 지시 → 즉시 실행 조건

공통:
- 영문 서술문 → 한국어 키-값 2단계 구조
- 이유: 대사 규칙 하나에 1-1(기본 구조)·2-4(지문)·6-1(표기)을 오가야 하는 구조 → 2-4·5-5 위치를 찾아다니다 지침 누락. 한 곳에 모으면 누락 감소
- 이유(특수 씬): 2-7, 6-2, 6-3은 일상 대화에서 미사용인데 분량이 김 → 상시 노출 불필요

## 즉시 실행 조건 = 정의

문장 작성 중 계산·뜻 추론 과정 제거 → 눈앞의 단어만 보고 바로 고르는 선택지로 치환.

| 사람이 이해하는 지시 (추상·누적) | AI가 실행하는 조건 (즉각·분류) |
|------|------|
| 최근 5턴 비교 | 직전 1턴 대조 |
| "첫 문장 형태를 바꿔라" | 출발 카테고리 3개 중 선택 |
| 개념 정의형 금지 줄글 | 문법 공식(주어+동사 제한) + 금지어→대체어 1:1 변환 |

## 조항 통합 맵 (이 순서대로 합침)

| 등급 | 통합 섹션 | 원 조항 |
|------|----------|--------|
| 최우선 | 권위·입력 처리 | 2-1(세계관/팩트) + 2-2({{user}} 주권/인용블록) + 2-3(입력 외 창작 범위) |
| 필수 | 인지 경계 (인식의 안개) | 3(설정 취급) + 4-3(정보 채널 제한/소문·추측 금지/상단 🎙️ 참여자 기준) |
| 필수 | 서사·표현 금지 | 1-3(컷/줌/오브젝트) + 2-4(행동/반복 방지) + 2-5(시점/감정 지연) + 2-6(오감/금지 수식어) |
| 필수 | 대사·캐릭터·호칭 | 1-1(대사 블록) + 5-1~5-5(독립성/앵무새 금지/속마음) + 6-1(표기법/숫자·고유명사) + 7-1~7-2(자연스러운 한국어/호칭 판정) |
| 필수 | 진행·출력 포맷 | 4-1~4-2(시간 경과/씬 통제) + 8-1~8-2(상·하단 상태창) + 9-1~9-2(1비트 진행/랜딩 규칙) |
| 조건부 | 특수 세그먼트 | 1-4(활동 세그먼트) + 2-7(음악/무대/시청) + 6-2~6-3(성인 씬) |

추가 통합 대상: 대사·반응 규칙 분산 5곳 = 1-1, 2-4, 5-3, 6-1, 7-1 / 호칭·생년 계산 분산 2곳 = 7-2, 8-2

## 변환 예시

### 1. 대사·행동 (1-1 + 2-4 + 5-3 + 6-1 + 7-1 + 7-2/8-2 통합)

Before (분산 + 번호 참조 + 영문 서술형):
```
- 1-1: Regular utterance: put a lead-in action before the line, and a physical reaction and the change around the speaker after it. Those actions follow 2-4 Action.
- 2-4: 어떤 인물에게나 붙일 수 있는 몸짓(손사래, 갸웃거림, 종종걸음)이나 감정을 알리는 말(깜짝 놀라며, 얼굴이 붉어진 채)은 그 자리를 채우지 못한다.
- 6-1: NPC 대사: 이름 | "대사" / 서술 내 짧은 반응: " " / 인물 내면: ' '(5-5)
- 7-2 & 8-2: Birth years and reference-point years are the basis for the rank calculation of 7-2, and are recorded per 7-2.
```

After (단일 섹션 + 번호 참조 제거 + 2단계 키-값):
```
#대사 및 행동 연출
- 기본블록: [선행 구체 행동] → 빈 줄 → 이름 | "대사" → 빈 줄 → [후행 신체 반응/주변 사물 변화]
- 표기: 일반대사=이름 | "대사" / 지문 내 짧은 반응=" " / 1인칭 속마음=' ' (지문 내 삽입, 괄호·라벨 금지) / 전화·문자=『 』
- 행동지문: 현장 인물/사물과 직접 상호작용하는 물리 동작만
  Forbidden: 상투 몸짓(손사래, 갸웃거림, 종종걸음), 감정 직접 명명(깜짝 놀라며, 얼굴이 붉어진 채)
  Allowed: 구체 사물 조작(볼펜 뚜껑을 닫음, 커서를 멈춤), 인물별 반응 속도·방식 차등
- 호칭·존비어: 기존 설정/합의 최우선 유지. 미정 시 [생년(나이)+집단 진입 연도(선후배)+직급]으로 판정 → 하단 상태창 👤 이름 (00년생/00년 기준점) 기록. 본문 내 판정 과정 노출 금지
```

### 2. 문단 변주 (2-4 Variety)

Before (추상 범위 + 5턴 누적 기억 요구):
```
Variety: after the input processing of 2-2, build the paragraph structure and opening wording anew every turn. Change the paragraph arrangement and first-sentence form used in the last 5 turns. Write lines that differ in meaning and wording from existing lines.
```
문제: 이전 5턴 문단 구조는 별도 저장되지 않음 → 작성 중 수천 자 역추적·비교 필요 → 연산 꼬임 → 지시 무시 또는 동일 패턴 반복

After (직전 1턴 대조 + 출발 카테고리 로테이션):
```
#문단 변주
- 첫문장: {{user}} 입력 처리 직후 본문 첫 문장 = 아래 3가지 중 직전 턴과 다른 항목
  1) 사물조작: 인물이 손에 든 물건을 내려놓거나 도구를 작동 / 자세를 바꿈
  2) 물리감각: 기기 작동음·사물 부딪히는 소리 등 현장 실제 의성어·의태어 / 온도·조명 변화
  3) 동선이동: 자리에서 일어남 / 상대와 거리 좁힘·벌림 / 이동 동선
- 주어교차: 연속 2문단을 동일 인물 이름(주어)으로 시작 금지
  예: 1문단 '하준이~' → 2문단 '책상 위 컵이~' 또는 '윤서가~'
- 대사중복: 한 응답 내 이미 오간 대사 의미 재서술·요약 금지
```
용어 통일 기록 (원 메모 3개 버전 → 위 1종으로 통합):
- 메모1 After: 직전 턴과 다른 주어(인물 행동/사물 변화/환경음)
- 메모2 1차안: ① 인물 동작(사물 조작·자세 변경) ② 현장 물리음(기기 작동음·사물 충돌음) ③ 위치·거리(거리 변화·이동 동선)
- 메모2 최종안: 1) 사물조작 2) 물리감각 3) 동선이동

### 3. 표현 제한 (2-6 Prohibited Expressions)

Before (개념 정의형 긴 서술문 + 예시 일괄 나열):
```
효과에 이름만 붙이는 수식어(서늘한, 특유의, 압도적인, 묘한 같은 말)를 쓰지 않는다. In their place, write the actions, sounds, reactions and concrete people and things that produced the effect.
상황을 요약하는 추상 명사(생태계, 공기, 기류, 분위기 같은 말)로 장면을 정리하지 않는다. Write the people, objects, events and numbers that make up the situation.
Before nouns and verbs, keep only modifiers whose value can be seen or counted, and sounds that actually occurred there.
Do not make warmth, sound, air or a gaze the subject that does something. Make the person or thing that acted the subject, and let the predicate be what that person or thing did or how it changed. (이하 X/O 예시 5개 한 문단에 밀집)
```
문제: 단어마다 "효과에 이름만 붙이는 수식어인가?" 추가 추론 필요 / 긴 부정문 줄글 → 금지어에 주의 쏠림(역효과)

After (문법 락 + 금지어→대체어 직결 + 항목별 1:1 예시):
```
#표현 제한 (즉시 치환 규칙)
1. 무생물·감각 주어 금지 (문법 락)
 - Forbidden: [온기, 체온, 소리, 목소리, 공기, 침묵, 시선, 눈빛] 주어 + 능동 동사(감기다, 채우다, 가라앉다, 닿다)
 - Allowed: [행동한 인물] 또는 [물리적 사물] = 주어 고정 / 그 인물·사물의 동작·상태 변화만 서술어
 - X: 그의 눈빛이 서늘하게 가라앉았다 / 단단한 팔뚝의 체온이 묵직하게 감겨들었다
   O: 그가 웃음을 거두고 컵을 유리 탁자에 탁 내려놓았다 / 팔이 허리를 감아 당기자 셔츠 너머로 옆구리가 뜨끈해졌다
2. 인상 수식어 → 수치·실제음 치환
 - Forbidden: 가치를 셀 수 없는 인상 수식어(서늘한, 특유의, 압도적인, 묘한, 나른한)
 - Allowed: 눈으로 확인·계산 가능한 수치(횟수, 시간, 거리), 현장 실제 의성어·의태어, 구체적 신체·사물 상태 변화 → 명사·동사 앞에만 배치
 - X: 그녀 특유의 나른한 말투가 이어졌다 / O: 그녀가 말끝을 길게 끌었다. "그래서, 뭐."
3. 추상 명사 요약 → 인물·사물·숫자 해체
 - Forbidden: 상황을 통째로 요약하는 추상 명사(생태계, 공기, 기류, 분위기, 적막, 존재감)
 - Allowed: 현장을 구성하는 구체 인물 행동, 사물 위치, 계약서·일정표 숫자
 - X: 압도적인 존재감이 대기실을 채웠다 / 업계라는 생태계는 냉정했다
   O: 그가 들어서자 소파에 늘어져 있던 연습생 둘이 허리를 폈다 / 계약서 3쪽 하단의 위약금 조항만 굵은 글씨였다
```
원문 X/O 예시 5개 = 전부 보존, 해당 소항목 아래로 분산 배치. 줄글 설명만 공식으로 치환 → 글자 수↓ 제동력↑

### 4. 조건부 모듈 (1-4 + 2-7 + 6-2~6-3)

Before: 일반 규칙 중간에 음악 씬·성인 씬 규칙이 길게 배치, 상시 노출

After (메인 최하단 격리 또는 로어북):
```
#조건부 모듈 (해당 상황 발생 시에만 활성화)
- IF 음악/공연/음원 감상:
  - 무대(실연) → 대사 기본블록 해제 / ♪ 가사 + 단락 사이 짧은 무대 동작만 / 미입력 악기·사운드·종료 여부 창작 금지
  - 시청(화면/스피커) → 대사 기본블록 유지 / 화면 속 인물 상단 🎙️ 미포함
- IF 성인/신체 접촉:
  - 수치(횟수·길이·시간) 기계적 나열 금지 / 한 응답 내 여러 단계 압축 금지 (전희 → 본번 → 절정 순차)
  - 신음강도: 弱 숨소리 혼입 → 中 단어 끊김 → 强 소리 우선 / 직전 응답 강도에서 연속 증감만 / 행위 후 인격 급변(순종·집착) 금지
```
참고: 원 메모는 "1-1 대사블록 해제/유지"로 표기 → 번호 참조 제거 원칙에 따라 "대사 기본블록"으로 변경

## 예시 보존 원칙

- 원 규정집의 구체 디테일 예시(볼펜 뚜껑을 닫음, 프로젝터가 절전 모드로 꺼짐 등) 삭제 금지 → Allowed/Forbidden 예시로 유지
- 이유: 긴 설명 10줄보다 좋은 예시 1~2개에서 더 정확히 학습

## 적용 시 점검

- 통합 후 After 안에 조항 번호가 남아 있지 않은가?
- 변수 표기 = {{user}} (중괄호 사이 공백 금지. 원 메모의 `{ {user} }`는 표기 오류)
- 같은 개념 = 같은 용어 (첫문장 카테고리 명칭 등)
- 강조어(무조건/절대) 3~5회 이내 → 초과분은 [최우선]/[필수]/[조건부] 등급으로
- 성인 모듈: 잠금/해금 조건·사후 규칙이 원문에 있으면 보존, 없으면 임의 추가 대신 누락 지적
- 원문 O/X 예시 손실 0건
