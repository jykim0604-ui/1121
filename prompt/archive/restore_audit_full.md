# 초경량화 이전 프롬프트 전수 대조

대상: 초경량화를 만들기 직전의 `main_ko_compact.md`(커밋 7387601 직전)와 함께 쓰던 `hardlock_ko.md`
기준: 프리셋 기본 원칙 + 고정 토글(서술 시점·인칭 설정 준수, 거리 관찰·절제, 스포일러 보호,
현실 재현, 문학적, 표현 관습 설정·출처 준수, 성인물 설정 준수·자동), 현재 울트라라이트(7,771토큰)

판정 기준(프리셋은 출처가 있어야 작동하는 범용 엔진이라는 전제):
- **되살림**: 프리셋에 없거나 출처 역할을 하는 내용이고, 충돌이 없다
- **보류**: 프리셋과 일부 겹치거나, 테스트에서 문제가 보일 때 넣을 것
- **제외**: 프리셋이 같은 내용을 더 넓게 다루거나, 프리셋·토글과 충돌한다
- **있음**: 이미 울트라라이트에 있다
