# 출력 예시 3 (v5 단독) 문제점 — 예시 1·2와 비교

- 원문: `output_samples.md`
- 기준: 묘사, 대화 맥락, 문장, 지문 구조는 예시 2가 올바르다.
- v6은 폐기했다. 이 목록의 기준 시스템 프롬프트는 v5다.
- 1~4는 사용자 판정이고, 5~9는 비교하면서 추가로 찾은 문제다.

---

## 1. 구조: 정상 (끝맺음 반복만 주의)

- 판정: 정상.
- 마지막 질문("오늘 저희 누구부터 부스에 들어가면 될까요?")은 장면상 자연스러워 허용한다. 다만 매 턴 같은 방식으로 끝나면 안 된다.
- 비교: 예시 1·2·3이 모두 {{user}}에게 녹음 순서를 묻고 끝난다. 구성이 달라도 같은 끝맺음이 나왔다.
- 관련 v5 문장
  - 1-3 버튼: "직전 턴과 같은 방식으로 끝내지 않는다."
  - 9-1: 착지 예로 "말을 마치고 상대가 답하지 않은 자리"를 듦. 또 "{{user}}가 응답할 차례라는 것을 본문에 드러내지 않는다."

## 2. 호칭·말투: 설정과 다르게 무너짐

| 예시 3 | 예시 2 |
|---|---|
| 이안: "오빠!" + 반말, "김유진 이사님이라고 불러야 돼?" / 지우: "선배님" + 존댓말 / 유나: "오빠" + 존댓말 / 하람: "선배님" | 같은 양상 (이안 "오빠" 반말, 지우 "선배님", 유나 "오빠" 존댓말) |

- 두 예시 모두 설정과 다르다. 프리셋이 있든 없든 같은 오류가 나왔다.
- 해결 방향 (사용자 결정): 테스트용 프리셋 2의 [Before writing] 앵커처럼, 출력 바로 앞의 같은 자리에 효과가 높은 앵커를 둔다.
  - 참고 원문: "Keep the address and speech level each pair already uses, including what the settings and records show, as 3-1 sets; do not call someone 선배 who joined after the speaker, even when they are absent."
  - v5에서 그 자리는 문서 맨 끝(9-1 뒤)이다.

## 3. 대화 전개·화제: 부자연스러움

| 항목 | 예시 3 | 예시 2 (정상) |
|---|---|---|
| 첫 대사 | 이안이 들어오자마자 "이사님이라고 불러야 돼?" (호칭 화제를 바로 꺼냄) | 이안 "오랜만이야" → 지우의 반말 지적 → 이안의 반박. 호칭 화제는 지우가 사과하며 CPO 기사를 꺼낸 뒤에 자연스럽게 나옴 |
| 화제의 근거 | 하람 "얼굴이 조금 피곤해 보이세요", 이안 "다크서클 내려왔어. 또 밤새도록 기타 치면서 곡 쓴 거야?" (입력과 장면 어디에도 없는 {{user}}의 상태를 근거로 화제를 만듦) | 화제가 모두 장면에 있는 것(반말, 가방의 백참, 카드지갑, 기사, 가이드 음원)에서 나옴 |
| 화제 흐름 | 호칭 → 군기 → 가사지 검사 → (팔찌) → 피곤해 보임 → 기타 → 녹음 순서. 앞 대사와 이어지지 않고 튐 | 반말 → 반박 → 백참 폭로 → 맞폭로 → 사과·축하 → 호칭 → 밥 약속 → 녹음으로 돌림. 대사마다 앞 대사를 받음 |
| 정보를 다루는 방식 | 지우 "유진 선배님이 바쁜 시간 쪼개서 우리 미니 2집 곡 써주신 거니까", "PRISM A&R 과장님이 가이드 보컬 순서대로…": 유진이 이미 아는 것을 유진에게 설명함 | 정보는 놀리기나 사과처럼 말하는 이유가 있을 때 나옴 |

- 예시 1과 같은 실패: 예시 1도 입력에 없는 {{user}}의 상태(손목)를 화제로 만들고 "기타라도 쳤어?"로 이어 갔다. 예시 3도 같은 틀이다(피곤함 → 기타). 예시 2에는 없다.
- 관련 v5 문장
  - 3 "인물 간 대화는 상대가 아직 모르는 정보를 다룬다", "로어북 항목이 불려 왔다는 것만으로는 화제가 되지 않는다"
  - 2-1 "{{user}}의 일은 만들지 않는다"
  - 1-1 "후속 발화는 직전 대사의 내용, 말투, 행동을 받아 잇는다"
- 예시 2에서만 작동한 프리셋 문장
  - "Another character is not an interface for exposition, diagnosis or problem-solving; explanation, analysis and humor need that speaker's present reason."
  - "Use details the sources support or that follow from established conditions, never invented biography …"
  - "Let a speaker finish a connected thought …"

## 4. 묘사·표현: 부자연스러움

| 항목 | 예시 3 | 예시 2 (정상) |
|---|---|---|
| 굳은 몸짓 | "눈을 동그랗게 뜨고는 대열에서 쏙 빠져나와", "깜짝 놀라며", "얼굴이 붉어진 채 손사래를 치다가", "고개를 바짝 들이밀자", "톡톡 가리키며 고개를 갸웃거렸다", "슬그머니" | "고개를 꾸벅 숙이며", "고개를 불쑥 내밀었다"처럼 몸짓이 적고 짧음. 동작마다 사물과 목적이 붙음 |
| 감정 표시 | "깜짝 놀라며", "얼굴이 붉어진 채" (감정을 표지처럼 붙임) | 감정을 행동의 결과로 보여 줌: "입가를 가리고 웃음을 참았다", "오른손을 얼른 빼내며 … 팔뚝을 툭 쳤다" |
| 몸짓의 기능 | "포스트잇이 빽빽하게 붙은 가사지 파일을 두 손으로 고쳐 쥐며 유진의 얼굴을 살폈다" (화제와 무관한 장식) | "지우의 턱 밑에 정수리가 닿을 만큼 키 차이", "장비 랙 상단보다 머리 하나가 더 낮은" (배치와 관계를 보여 줌) |
| 예시 1과의 공통점 | 예시 1 "눈을 반짝이며 … 총총", "얼굴이 붉어진 지우가 손사래를 치며"와 같은 계열 | — |

- 효과에 이름만 붙이는 수식어(서늘한, 압도적인)는 예시 3에도 없다. v5 2-6은 작동했다.
- 남은 문제는 수식어가 아니라 굳은 몸짓과 감정 표지다.
- 관련 v5 문장
  - 2-6은 수식어, 추상명사, 출처 없는 비유만 다룬다.
  - 2-4 다양성은 앞선 응답의 형태를 되풀이하지 않는 것만 다룬다.
  - 굳은 몸짓 자체를 다루는 문장은 v5에 없다.
- 예시 2에서만 작동한 프리셋 문장
  - "Let the scene carry emotion and meaning through what people do, say, avoid and how their bodies respond."
  - "Keep connecting prose plain, speech tags simple, and action beats for actions that matter."
  - Prose style Literary
  - Composition Description-led
