# WC 지시형 문장 목록과 처리안

기준: WC는 설정이다. 세계가 어떤지, 업계 사람들이 어떤지를 적고, 무엇을 쓰라/어떻게 말하라는 문장은 두지 않는다. 화제는 일 얘기 대전제, 평가 대전제(+이유), 열린 얘깃거리만 남긴다. 인물 유형(원 WC-7)은 대상에서 뺀다.

처리: 유지 / 설정형 전환(내용 그대로, 문장만 사실 서술로) / 삭제(v7이 이미 맡거나 v7과 충돌)

## 원 WC-7 계층별 처지와 관계 방식

대상에서 제외, 그대로 유지(번호만 WC-6). "관계 방식"이라는 말이 v7 5-4 "인물의 설정이나 관계 방식이 더 빠른 접근을 요구하면 그에 따른다"와 그대로 맞물린다.

## 장르 줄

유지. 태그를 읽는 방법(체크리스트 아님, 구체적인 지시와 설정이 앞섬)을 정하는 문장이라 지시형이지만, 요청한 줄이다.
