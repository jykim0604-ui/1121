# 시스템 프롬프트 v7 재검수 (단독 사용)

- 대상: `system_prompt_v7_ko.md` (18,589토큰, Gemma 3)
- 목표: 시스템 프롬프트 단독으로 ① 구조 ② 문체가 문제없이 출력될 것
- 방법
  - 정적 시뮬레이션. 입력마다 한 턴의 흐름(입력 처리 → 반응 → 묘사·문체 → 전개 → 착지)을 v7 문장에 맞대었다.
  - 실제 출력 근거로 출력 예시 3(v5 단독, `output_samples.md`)의 문제 목록(`v5_standalone_issues.md`)을 v7에 다시 대었다.
- 판정: **통과** / **관찰**(막는 문장 있음, 테스트에서 확인) / **위험**(막는 문장이 없거나 약함. 수정안 있음)
- 검증 단계: 문서 = 아래 / RisuAI 조립 = UNTESTED / 모델 출력 = UNTESTED

## 0. 이번에 반영한 것

| 위치 | 내용 |
|---|---|
| 1-2 머리말 | "문장 톤과 밀도, 사건 내용, 입력 순서는 가져오지 않는다" → "사건 내용과 문장, 입력 순서는 가져오지 않는다" |
| 1-2 「행동이 먼저인 입력」 | 지문을 유나에게 밀착해 다시 씀. 지문의 풀네임을 성을 뗀 이름으로. 속마음은 유나의 단락에 한 번("자다 깨서 들은 거면서."). "3시간" → "세 시간"(6-1 숫자 표기, v5 때부터 어긋나 있었음) |
| 1-2 「대사가 먼저인 입력」 | 지문을 도현에게 밀착해 다시 씀. 풀네임 수정. 마지막 문장은 서류를 건네는 동작(9-1 "건네고 받지 않은 자리") |
| 2-6 ⭕ 두 개 | "컵 바닥이 탁, 유리 탁자에 닿았다." / "닿은 자리가 뜨끈해졌다." 덧붙임 |
| 2-7 무대 예시 | 지문의 "윤채린이" 등 네 곳을 "채린"으로 |
| 2-7 채우는 것 | "1-3과 2-6의 '실제로 난 소리'에도 음악은 들지 않는다" (지난 검수 수정 필요 1) |

- 참조 번호 점검: 본문 안의 "n-n" 참조가 모두 실제 절을 가리킨다(자동 확인).
- ' ' 표기는 5-5의 금지 문장 안에만 남아 있다.

## 2. 흐름별 시뮬레이션

- 사례: A 사무실(대사로 시작, NPC 둘) / B 자율 전개(NPC 혼자 → 다음 장소) / C 나레이션 입력 뒤 여럿이 들어오는 녹음실 / D 감상 구간 / E {{user}} 혼자인 장면

| 단계 | 정하는 문장 | 판정 |
|---|---|---|
| 입력 처리 (A, B, C) | 2-2, 1-2 예시 세 개 | 통과 |
| {{user}} 상태 | 2-2 "{{user}}의 몸과 기분에 입력에 없는 상태를 지어 다른 인물이 반응하게 하지 않는다" | 통과 |
| 대사 블록 | 1-1, 6-1(화자 이름, 단독 줄, 말만, 괄호 지시 없음) | 통과 |
| 밀착 대상 (A, B) | 2-5 "특정 NPC" | 통과 |

| 서술자 논평 | 2-1, 2-5 "판단과 평가는 속마음과 대사로만" | 통과 |
| 감각·비유 | 2-6 | 통과. 비유 폭이 좁은 것은 관찰 |

## 4. 위험 수정안 (미반영)

### 위험 1. 호칭·존비어
- 상태: 사용자 결정으로 별도 프리셋(앵커)에서 처리한다. v7에는 넣지 않는다.
- 근거: 예시 3에서 7-2만으로는 무너졌다. 테스트용 프리셋 2의 [Before writing] 줄이 출력 직전 자리에서 이를 잡았다(사용자 결정: "같은 자리에 효과 높은 앵커링, 같은 방법으로 해결").
- 단독 사용에서 출력 직전 자리는 문서 맨 끝(9-1 뒤)이다.
- 수정안 A (권장): 9-1 끝에 한 줄
  > - 출력 전에 이번 응답의 대사와 속마음을 말하는 방향과 순서대로 읽고, 7-2에서 이미 정해진 쌍의 호칭과 존비어에서 벗어난 곳을 고친다. 확인 과정은 본문에 옮기지 않는다.
- 수정안 B: 7(한국어 자연성과 호칭)을 문서 맨 끝으로 옮긴다. 문장은 겹치지 않지만 절 번호와 참조를 모두 다시 매겨야 한다.

### 위험 2. 화제 전개
- 근거: 예시 3에서 지우가 유진이 이미 아는 일을 유진에게 설명했다. 예시 2에서 작동한 프리셋 문장: "Another character is not an interface for exposition, diagnosis or problem-solving; explanation, analysis and humor need that speaker's present reason."
- 수정안: 3 설정 처리의 "인물 간 대화는 상대가 아직 모르는 정보를 다룬다." 뒤에
  > 상대가 이미 아는 일을 그 사람에게 설명하지 않는다. 다른 인물은 설명, 진단, 문제 해결을 위한 창구가 아니며, 설명과 분석은 그 화자가 지금 말할 이유가 있을 때만 나온다.

### 위험 3. 굳은 몸짓, 감정 표지
- 근거: 예시 3 "깜짝 놀라며", "얼굴이 붉어진 채 손사래", "톡톡 가리키며 고개를 갸웃거렸다". 예시 2에서 작동한 프리셋 문장: "action beats for actions that matter", "Let the scene carry emotion … through what people do".
- 수정안: 1-1 일반 발화 "대사 앞에 전조 동작을, 대사 뒤에 신체 반응과 주변 변화를 둔다." 뒤에
  > 이 동작은 그 자리의 사람이나 사물을 상대로 하는 일로 쓴다. 어떤 인물에게나 붙일 수 있는 몸짓(손사래, 갸웃거림, 종종걸음)이나 감정을 알리는 말(깜짝 놀라며, 얼굴이 붉어진 채)로 채우지 않는다.
- (재설명 때 고침) 처음 안의 "감정이 실린 것만"은 손사래도 통과시킨다. 손사래는 당황이 실린 동작이기 때문이다. 예시 2와 예시 3을 가르는 기준은 동작이 그 자리의 사람이나 사물을 상대로 하는지다.
- 2-6의 의태어 문장("그 자리에서 실제로 난 … 움직임에 쓴다")은 그대로 둔다. 위 문장이 어떤 움직임을 쓸지 정하고, 2-6은 그 움직임을 어떻게 쓸지 정한다.

- 세 수정안을 모두 넣으면 약 +150토큰(추정)이다.
