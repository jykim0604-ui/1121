# 시스템 프롬프트 v7 시뮬레이션 검수

- 대상: `system_prompt_v7_ko.md` 단독 사용 (프리셋 없음)
- 방법: 정적 시뮬레이션이다. 입력마다 한 턴의 흐름(① 입력 처리 → ② 반응 → ③ 묘사·문체 → ④ 전개 → ⑤ 착지)을 따라가며 v7의 실제 문장을 맞대었다.
- 판정
  - **통과**: 정하는 문장이 있고 서로 같은 방향
  - **관찰**: 막는 문장은 있으나 새기 쉬운 자리. 테스트에서 확인
  - **수정 필요**: 문장끼리 틈이 있거나 어긋남
- 검증 단계: 문서 = 아래 결과 / RisuAI 조립 = UNTESTED / 모델 출력 = UNTESTED

## 1. 예상 출력 (사례 A)

- 상황: 사무실, NPC 둘. 한지수(대리, {{user}}에게 해요체), 문태오(사원, 지수에게 해요체). 상태창 생략.
- 입력: "이거 몇 시까지 끝내야 돼요? 팀장님이 아까 뭐라 하셨는데" *서류를 넘긴다*

```
**{{user}} |** "이거 몇 시까지 끝내야 돼요?"

{{user}}가 팀장님이 아까 뭐라고 하셨던 것 같다며 서류를 한 장 넘겼다.

**한지수 |** "내일 아침 9시요. 회의 들어가기 전까지."

**문태오 |** "그럼 오늘은 야근 안 해도 되는 거죠?"

지수는 대답 대신 서류 더미를 반으로 갈랐다. 위쪽 절반을 들어 {{user}}의 책상 쪽으로 밀어 두었다.
```

## 3. 수정 필요

### 수정 필요 1. 2-7의 "실제로 난 소리" 제외 범위
- 지금: 2-7 「채우는 것」 "음악 외에 그 공간에서 난 소리. 1-3의 '실제로 난 소리'에도 음악은 들지 않는다."
- 틈: 지난 합본 C3에서 2-6에 "그 자리에서 실제로 난 소리"를 넣었다. 2-7은 1-3만 제외하고 있어서, 2-6을 근거로 입력하지 않은 음악에 의성어나 소리 수식을 붙일 수 있다. 2-7 「입력하지 않은 것」("음악은 연주했다, 불렀다, 틀었다, 들었다는 사실만 쓴다")이 대부분 막지만, 두 절의 말이 어긋난다.
- 수정안: "1-3의 '실제로 난 소리'에도" → "1-3과 2-6의 '실제로 난 소리'에도"
