# v4 최종본 재검수 (단독 사용, 가이드 기준)

- 대상: `system_prompt_v4_ko.md`
  - 3-6을 독립 절로 둔 판, 제목은 `[이 작품의 고정 지시]`로 되돌림
  - 프리셋 가정 없음 (`preset2_v4.md`는 지움)
- 범위: 문체와 묘사 밀도는 제외했다. 한 턴이 처리되는 흐름을 따라가며 구조와 지침이 서로 부딪히는 곳만 찾았다.
- 한 턴의 흐름:
  1. 머리말
  2. 9 상단 상태창
  3. 3-2 입력 처리
  4. 3-3 본문 시작
  5. 2-1·2-3·5·6·7·8 본문
  6. 10-2 착지
  7. 9-2 하단 상태창
- 수정안은 아직 반영하지 않았다.
