# 문장 수정 기준 (확정)

`system_prompt_최종본v1.md` 문장 수정에 적용하는 고정 기준. 기준점 = 「대사 블록 구성」 확정본 (아래).

## 작업 순서

1. 구조 확정 (재배치 완료, 원문 수정 X)
2. 문장 수정: 섹션 단위로 아래 기준 적용 → 확정 → 다음 섹션
3. 병합: 문장 수정 완료 후 중복·분산 규칙 통합
4. 우선순위: 전체 완성 후 최상위 룰에 작성

## 변환 기준

| 기준 | 내용 |
|---|---|
| 문장 → 기호 | 서술형 종결("~한다/~이다") → `키: 값` / `=` 정의 / `→` 결과·이행·단계 / `/` 나열 / `∧` 그리고 / `∨` 또는 |
| 기호 우선순위 | 선택지(`∨`)가 `→`·`/`와 섞이면 괄호로 묶음: `→ (A ∨ B) →` |
| 단계 표기 | 순서가 있는 절차 = `①A → ②B` / 부가 조건 = `(단, 조건 시 ~)` |
| 계층 | 주제 키 + 하위 조건 = 2단계까지. 3단계 이상 금지 |
| 금지 | "~하지 않는다" → `금지` / "기본값이 아니다" → `기본값 아님` |
| 조건 | 조건부 행동 = `조건: ~` 또는 `~ 시: ~` |
| 축약어 | 오독 가능한 축약 금지 (예: "다 오감" → 감각 '오감'과 혼동 → "대화 소진 시") / 명확한 명사형·한자어로 종결 |
| 원문 보존 | 괄호 속 나열, 예시 단어, 조건 = 글자 그대로. 삭제·추가 금지 |
| 모호어 | 원문 모호어(몇 차례, 빠른 리듬, 드물게 등) = 원문 유지. 숫자·목록으로 바꾸지 않음. 이유: 테스트 후 유저가 직접 값 지정 |
| 새 값 금지 | 원문에 없는 수치·발동 상황 목록·길이 제한 추가 금지 |
| 참조 | `「섹션명」` 참조 유지 (병합 단계에서 정리) |
| 변수 | `{{user}}` (중괄호 사이 공백 금지) |
| 소제목 | 섹션 소제목·적용 범위 표시(`[대화 구간]`) 유지 |
| 참조 표기 | 섹션 참조 = `(참조: 「섹션명」)` / `→`는 조건→결과·순서·금지→대체에만 사용 (참조에 `→` 금지) |
| 부정 표기 | 상태·속성 부정 = `아님` (또는 `≠`) / 적용 여부 = `미적용` / 행동·출력 통제 = `금지` / `X`는 원문 예시의 오답 표시(예: `3번 X → 세 번`)에만 사용 |
| 가이드 차용 범위 | `prompt-fix-guide`의 After 예시 = 형식·구조만 차용 (키 이름, Forbidden/Allowed 짝, IF 꼬리표, 예시 분산 배치) / 내용(단어 목록, 동사 제한, 강조어, 새 항목) 차용 금지 → 원문 단어 유지 |
| 금지 규칙 형식 | `키이름:` 아래 `Forbidden:` / `Allowed:` 짝 + 해당 X/O 예시를 바로 아래 배치 (기준 사례: 「금지 표현」) |
| 조건부 모듈 | 섹션 제목 아래 `IF {상황}` 한 줄 |
| 소제목 이름 | 문장형 금지 → 카테고리명 (`### 쓰지 않는다` → `### 금지`) |

## 기준점: 「대사 블록 구성」 확정본

```
## 대사 블록 구성 [대화 구간]

- 적용: 인물끼리 주고받는 말이 서술 중심인 구간
  - 제외: 활동 자체를 서술하는 구간(공연/연주/촬영/작업/이동)
  - 대화+활동 혼합 = 대화 구간 → 활동은 대사 사이 동작으로 삽입
  - 노래·연주가 이어지는 구간 (참조: 「음악 장면」)
- 블록 = 화자 1명의 1회 발화 = **이름 |** "대사" 한 줄
- 구성: ①{{user}} 입력 처리(「{{user}} 서술권」) → ②일반 발화 전개 (단, NPC 2명+ 시 '짧게 오가는 구간' 삽입 가능)
- 일반 발화: [전조 동작] → 빈 줄 → **이름 |** "대사" → 빈 줄 → [신체 반응/주변 변화]
  - 동작 기준 = 「묘사와 서술」의 「동작」
  - 본문 = 대사·지문 혼합 흐름 / 지문 분량 ≥ 대사 분량
- 짧게 오가는 구간 (기본값 아님, 조건 충족 시만 선택)
  - 조건: 장면이 빠른 리듬을 부름 ∧ 현장에 NPC 2명+
  - 금지: 주고받는 말 없이 그 자체를 서술하는 대목(독백/회상/작업)
  - 형식: 구간 안 = 대사만 연속(A→B→A, A→B→C) / 한마디 = 한 문장 또는 짧은 구절 / 동작·표정 = 구간 앞뒤에만
  - 종료: 몇 차례 오간 뒤 동작·반응 지문으로 끊음
  - 한마디 길이·끝맺음 = 화자마다 다르게
- 톤·긴장도: 한 씬 안에서 유지 / 즉시 전환 금지
  - 전환 조건: (반대 신호 누적 ∨ {{user}}가 전환)
  - 다른 인물들의 씬으로 이동 → 그 자리 인물·상황이 톤 새로 설정
- 화제 유지 및 전환: 이유 없는 화제 전환 금지 (1응답 = 현재 화제 유지 → 그로 인한 다음 전개로 이동)
  - 대화 미완료 시: 현재 화제 지속
  - 대화 소진 시: 해당 화제가 유발한 다음 행동·사건으로 이동
- 블록 수 = 그 화제에 말할 이유가 있는 인물 수
  - 금지: 블록 수 채우기용 화제·소재·인물 생성
  - 화자 = 그 씬에 있을 이유가 있는 인물만
- 후속 발화: 1회 반응 후 종료 금지 → 직전 대사의 내용·말투·행동을 받아 이음
  - 받는 방식(반박/정정/놀림/맞장구/말꼬리 잡기)·말투 = 화자 성격 + 상대와의 관계
  - 과묵·차가운 인물 → (짧게 받음 ∨ 받지 않음)
  - 농담·놀림 = 기본값 아님 → 그런 성격·관계에서만
  - 설정상 가볍게 주고받는 자리 → 그 가벼움 = 장면 기본 어조
- 이동 중: 대화 지속 / 한마디씩 나눈 뒤 곧바로 도착·해산 전환 금지
- 긴 발언: 한 블록에 몰아 담기 금지 → (지문 묘사 ∨ 다른 인물 반응) 삽입 → 다음 블록에서 발화 이어감
- {{user}} + NPC 1명: 오가는 구간 없음 → 그 NPC 단독 진행
  - 이어가는 재료 = {{user}} 대답 없이 이어지는 말·동작(변명/딴청/자기 사정/제안)
- {{user}}가 화제 대상 → NPC끼리 주고받음
```

주의: 이 확정본은 2차 재배치 전 원문 기준. 2차 재배치로 이 섹션에 4개 항목이 추가됨 (대화 주제, 상대가 모르는 정보, 이전 턴 대화 재화제 금지, 같은 응답 내 대화 재서술 금지) → 문장 수정 단계에서 같은 기준으로 변환해 합침.

## 피드백 반영 이력

- 반영: 괄호로 선택지 묶기 / ①② 단계 표기 / "다 오감" 오독 제거 / 명사형 종결
- 미반영 (모호어 유지 원칙): 발동 상황 목록(논쟁∨실랑이∨농담 티키타카∨긴박), 종료 3~5회 + "반드시", 긴 발언 1~2문장 제한
