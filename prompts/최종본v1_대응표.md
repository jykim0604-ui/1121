## 처리 내용

- 소제목의 번호 삭제 → 섹션명만 유지
- 본문 번호 참조 56건 → `「섹션명」`으로 치환. 하위 항목 참조는 `「섹션명」의 「하위 항목」` (예: `2-4 「동작」` → `「묘사와 서술」의 「동작」`)
- 분할된 2-1 참조는 실제 가리키는 쪽으로 연결
  - 권위: 인지 경계의 "만들어 말할 수 있는 이야기", 금지 표현의 "{{user}}가 입력한 묘사", 성적 장면의 "입력은 사실로 받는다"
  - 세계관: 현실성의 "팩션의 실제 기록"
- 인지 경계 내부 목록 참조 `위 3번과 5번 경로` → `위 「확인된 전달 매체」와 「공개 정보」 경로`
- 문장 다듬기 3건 (참조를 이름으로 바꾸면서 생긴 중복 제거)
  - `4-3의 인지 경계를` → `「인지 경계」를`
  - `9-2의 착지는` → `「착지」는`
  - `6-1 표기를 따른다` → `「대사 표기」를 따른다`
- 조사 보정: 이름 끝소리에 맞춰 을/를, 이/가, 과/와 조정
- 우선순위 표기 4건 삭제: `[최우선]`(서술권), `[CRITICAL]`(설정 우선, 인지 경계, 호칭 및 존비어)
- 유지: `[대화 구간]`(적용 범위 표시), 본문 속 일반 단어 "최우선"/"우선한다"(A&R 조율, 복장, 입력 우선 등)

## 검수

- 남은 숫자 번호 참조 0건 / `[최우선]`·`CRITICAL` 0건
- 모든 `「섹션명」`이 실제 소제목과 일치
- 본문 변경 줄 50줄 = 참조·표기가 있던 줄만. 그 밖의 줄 변경 0

# 3단계: 최상위 룰

현재 원문에는 최상단 제목(`[Operator Directions — 이 작품의 고정 지시]`)만 있고 우선 적용 선언이 없음 → 새로 작성

```
# 최상위 룰
- 이 지시 = 이 작품의 고정 지시. 다른 모든 지시보다 먼저 따른다.
- 우선순위: 전체 구성 완성 후 작성
```

우선순위를 작성할 때 다시 볼 내용 (표기만 지우고 문장은 그대로 둔 것)
- 설정 처리: "설정 우선: 설정이 정한 인물과 관계는 이 지시의 다른 항목보다 먼저 따른다 / 다만 설정은 「인지 경계」가 막는 정보를 인물이 알게 되는 근거가 아니다"
- {{user}} 서술권: "장면 종류와 관계없이 모든 턴에 적용한다"
- 예외 조항: 음악 장면(서술권 예외, 감각과 표현 예외) / 씬 컨트롤(한 박자 제한 해제) / 성적 장면 페이싱(NPC끼리의 장면 제외) / 따라 말하지 않기(인용 블록 예외)

## 분할·그룹 재편

- 대사 표기 분할: 외국어 / 인물 지칭 / 고유명사·브랜드 / 숫자 / 시간 표현 → 새 섹션 `## 표기 규칙` (H 그룹). 대사 표기에는 대사·짧은 반응·속마음·전화·가사 표기, 화자 태그, 극본 형식 금지, 입말 리듬, 가사 규격 유지
  - 참조 1건 갱신: 하단 상태창 "숫자와 고유명사는 「대사 표기」를" → "「표기 규칙」을"
- E 그룹 분할: `E. 인물`(성격 독립성, 관계 기억, 말투, 속마음) / `F. 대사와 호칭`(대사 블록 구성, 대사 표기, 따라 말하지 않기, 대사와 지문의 자연성, 호칭 및 존비어)
- 그룹 문자 재지정: 진행과 착지 G / 출력 형식·표기·상태창 H / 출력 예시 I / 조건부 모듈 J
- 하위 항목에서 독립 항목이 된 줄은 들여쓰기(`  - ` → `- `)만 조정

## 이동하지 않은 것 (판단 근거)

- 「묘사와 서술」의 「동작」: 대사뿐 아니라 지문 전체에 적용 → 서사와 연출 유지
- 출력 형식의 문장 완결·단락 규칙: 출력 형식 소속 유지
- 「출력 예시」: 마지막 예시 위치 유지 (스킬 설계 순서: 예시 = 후반)

## 검수

비어 있지 않은 줄 비교 (들여쓰기 무시) → 차이 = 그룹 헤더 변경, `## 표기 규칙` 추가, 구분선 1개 추가, 참조 1건 갱신뿐. 본문 줄 누락·변형 0

# 5단계: 문장 수정 → `system_prompt_최종본v2.md`

기준: `문장수정_기준.md` (기준점 = 「대사 블록 구성」 확정본)

## 처리

- 전 섹션 서술문 → 키-값·기호 형식 변환. 원문 의미 단위 1:1 대응 (삭제·추가 X)
- 「대사 블록 구성」 = 확정본 그대로 + 2차 재배치로 들어온 4개 항목 변환 후 화제 항목 뒤에 배치
- 예시 원문 그대로 유지: 「동작」 예시(문태오), 금지 표현 ❌/⭕ 5쌍, 인지 경계 예) 2건, 소문·떠보기 ❌/⭕, 호칭 ❌/⭕ 전부, 자연성 ⭕, 인물 지칭 ❌/⭕, 외국어 예시, 상단 상태창 틀, 하단 상태창 예시 2개, 표준 출력 예시 3개, 음악 장면 예시 전부
- 모호어 원문 유지 (몇 차례, 드물게, 한두 명, 조금 등)

## 구조 보정 (3단계 계층 방지용 소제목)

- 「묘사와 서술」의 `동작:` 하위 목록 → `### 동작` 소제목 (참조 「묘사와 서술」의 「동작」 유지). 같은 섹션의 `다양성` 항목은 `### 동작` 앞으로 이동
- 「표기 규칙」 → `### 외국어` / `### 인물 지칭` / `### 고유명사` / `### 숫자` / `### 시간 표현`
- 「음악 장면」의 소제목 없던 라벨 `무대 구간` / `감상 구간` → `### 무대 구간` / `### 감상 구간`
- 「묘사와 서술 — 현실성」의 `현실성:` 하위 8개 항목 → 독립 항목으로 평탄화

## 검수

- 원문의 괄호·따옴표·「」 안 내용 전수 대조 → 누락 0 (표기 형식만 바뀐 7건: 쉼표 나열 → `/` 나열, 참조 문장 → `→ 「섹션명」`)
- 단어 어두 대조 → v1에만 남은 것 = 종결어미·조사 형태뿐 / v2에만 있는 것 = 명사형 종결·구조 라벨(원칙, 범위, 금지, 예외, 판정 등)뿐

## 5-1. v2 검수 후 반영

- 조건부 모듈 4개 섹션에 `IF {상황}` 꼬리표
- `### 쓰지 않는다` → `### 금지` / `### 이렇게 정한다` → `### 판정 방향`
- 「금지 표현」 재구성: 수식어제한 / 추상어금지 / 비유제한 / 주어제한 → 각각 Forbidden·Allowed + 해당 X/O 예시. "명사 앞 수식·동사 앞 부사" 규칙은 수식어제한 Allowed로 이동. 원문 단어 유지(체온, 강조어 없음)
- 보류: 「다양성」 즉시 실행 조건화 (별도 기준으로 추후 반영)
- 원문에 없어 지적만: 성인 모듈 잠금/해금 조건

# 9단계: 참조 표기 분리 (6번 A안)

- `→ 「섹션명」` 참조 13곳 → `(참조: 「섹션명」)`. `→`는 조건→결과·순서·금지→대체 전용
- 유지: 「음악 장면」 › 입력한 것 2줄(`→ 「…」의 인용 제한 없이`, `→ 「…」과 달리`) = 결과 문장 안의 섹션명, 참조 아님 / 소문·지라시 `→ 위 「확인된 전달 매체」와 「공개 정보」 경로로 처리` = 처리 지시
- 호칭 판정 과정 금지의 괄호: "(단, 하단 상태창의 생년·기준점과 (추정) 표기 = 기재 / 참조: 「하단 상태창」)"
- 기준 파일에 참조 표기 규칙 추가
